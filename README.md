GorillaPunch helps you find and prioritize issues before launch. Check development, staging, and live sites, then review a clear Launch Gate decision and the evidence behind it.

## Get GorillaPunch for Windows

- [Download the installer](https://github.com/emireln/gorillapunch/releases/latest/download/GorillaPunch-Setup.exe)
- [Download the portable app](https://github.com/emireln/gorillapunch/releases/latest/download/GorillaPunch-portable.exe)

## Reports and account sync

Save reports on this device, or sign in or create an account and choose Cloud sync in Settings to keep report results with your account. Screenshots stay on the computer that ran the audit.

## What you can do

- Check a site before release and get a prioritized list of findings.
- Review launch blockers, accessibility, performance, security, search visibility, and errors.
- Use the project monitor to run another check after you save code.
- Keep completed report results available across your signed-in devices with Cloud sync.
- Choose a quick or full audit and adjust how much of a site to check.

## Build from source

The project requires Node.js 22 or later and npm 10 or later. From the repository root, install dependencies with npm install, start the desktop app with npm run desktop:dev, run checks with npm test, and create a Windows installer with npm run desktop:package.
